# CI/CD

Read `docs/cicd.md` (repo-relative) in its entirety before answering questions
about, or making changes that affect, deployment, environment promotion, or GitHub
Actions workflows. It is the canonical source for this repository's
CI/CD pipeline (the pull-request checks, and the main → published →
staging → sandbox/prod-test → prod promotion chain, including which
checks gate each branch). Do not summarize or copy its content here —
always read the live page, since it may be revised independently of this
skill.
